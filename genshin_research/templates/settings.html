Gunakan key dari proyek yang mengaktifkan YouTube Data API v3. Key juga dapat disediakan sebagai environment YOUTUBE_API_KEY. Key yang dimasukkan lewat form perlu diisi kembali setelah server berhenti.

2. Pilih operasi yang digunakan

Untuk mencoba data manual, biarkan offline aktif. Untuk menggunakan data nyata, nonaktifkan setelah dasar penggunaan diperiksa dan lengkapi catatan pada bagian 3. Aktifkan hanya operasi yang dicakup catatan tersebut.

3. Catatan penggunaan dan masa simpan

Checkbox dan catatan mendokumentasikan keputusan proyek, bukan memberikan izin dari YouTube. API key dan status akademik tidak otomatis membuktikan seluruh hak penggunaan turunan. Memperpendek retensi memperpendek batas data yang ada; memperbesarnya tidak memperpanjang tanggal kedaluwarsa lama. Paket kedaluwarsa dihapus ketika aplikasi aktif dan tidak ada proses berjalan. Ekspor/cadangan di luar aplikasi perlu dikelola sendiri.
