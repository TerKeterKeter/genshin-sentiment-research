# Verifikasi metadata kandidat

Instruksi terpadu tersedia di [panduan pengguna](USER_GUIDE.md): penempatan API key, konfigurasi scope metadata, pengambilan bukti API, pengisian registry manual dan retensi.

Perintah metadata hanya memakai videos.list/channels.list. Kecocokan kanal dan durasi singkat tidak otomatis membuktikan Short tersebut pengumuman awal/drip marketing. Keputusan tetap dilakukan manusia.

Untuk teman yang mencoba, gunakan [checklist pengujian](TESTING.md). Ketentuan penggunaan tetap dirangkum pada [catatan kebijakan](policy-review.md).
