# Verifikasi metadata kandidat

Gunakan halaman **Kandidat & verifikasi** pada aplikasi browser. Instruksi lengkap tersedia pada [panduan pengguna](USER_GUIDE.md). Tombol metadata hanya memakai videos.list/channels.list, tidak mengambil komentar.

Judul, channel ID dan publikasi berasal dari API. Keputusan drip marketing, sumber pengumuman awal dan inclusion_status tetap ditentukan manusia. Untuk tahap koleksi, NLP dan analisis, gunakan scope terpisah pada Pengaturan sesuai dasar penggunaan yang berlaku.

CLI metadata lama tetap dapat dipakai untuk pekerjaan teknis. Untuk trial pengguna, [checklist browser](TESTING.md) adalah jalur utama.
